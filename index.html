01 / Learning Goals

這一課，我們要學會甚麼？

從知識、技能到態度，三個方向一起出發，讓你走進共生池時，眼睛、雙手和腦袋都準備好。

📘

知識

  • 說出魚菜共生五要素的角色：魚、菜、細菌、水、陽光
  • 描述氮循環三步：氨 → 亞硝酸鹽 → 硝酸鹽
  • 解釋光合作用如何為整個系統提供能量
  • 說明「水」作為運送媒介的作用
🔍

技能

  • 有系統地觀察共生池的水色、魚、菜根與氣泡
  • 把五張卡拼成一個正確的循環圖
  • 用「因為……所以……」口頭說出因果關係
  • 與組員分工合作、輪流記錄與匯報
💚

態度

  • 欣賞大自然萬物互相依存的共生智慧
  • 愛護池中生物：不拍打、不投餵、不捕捉
  • 珍惜水資源，明白循環再用的價值
  • 尊重組員意見，耐心聆聽與合作

02 / Five Elements

五要素角色：缺一不可的共生團隊

魚菜共生不是「魚 + 菜」這麼簡單，而是五個角色各司其職、互相支撐的系統。

👉 點擊卡片，看看每個角色在系統裡做甚麼。

🐟

魚

排廢者・養分起點

魚吃飼料後把蛋白質分解，經鰓和排泄物把含氮廢物「氨」排到水裡。牠是整個循環的養分起點，但氨太多會令牠自己生病。

點擊看角色

🌿

菜（植物）

吸收者・淨水高手

菜根浸在水裡，直接吸收硝酸鹽來製造蛋白質和葉綠素，長葉長根。它一邊吃「肥」，一邊把水變乾淨，是系統裡的天然濾水器。

點擊看角色

🦠

細菌

轉化者・隱形功臣

硝化細菌住在生物球、砂石和過濾棉的表面。牠把有毒的氨一步步轉成亞硝酸鹽，再轉成植物能用的硝酸鹽，是整個系統最關鍵的橋樑。

點擊看角色

💧

水

媒介・運輸大隊

水把養分送到植物根部、把廢物帶到細菌區、再把潔淨的水送回魚池。它像一條馬路，讓所有角色可以「互相見面」。

點擊看角色

☀️

陽光

能量來源・幕後老闆

植物靠光合作用把光能變成養分，同時放出氧氣供魚呼吸。沒有陽光，植物長不大，整個循環就沒有能量來源。

04 / Lesson Flow

35 分鐘流程摘要

由集合到總結，一節課走完「觀察 → 拼圖 → 表達」三個階段。

0–5 分鐘

集合・安全與觀察規則

在共生池旁集合，說明三不原則：不拍打水面、不投餵、不捕捉生物；分組並派發觀察記錄表。

5–10 分鐘

導入提問

「魚和菜為甚麼可以一起生活？」「魚的排泄物去了哪裡？」用兩個問題引出「共生」與「循環」的概念。

10–18 分鐘

實地觀察

分組用眼看、鼻聞（不觸摸）觀察：水是否清澈？魚的游動如何？菜根是甚麼顏色？水面有沒有氣泡？即時記錄在表上。

18–26 分鐘

小組拼循環圖

把「魚、細菌、菜、水、陽光」五張卡排成正確的循環，並用箭頭畫出養分與水的流向，找出細菌藏在哪裡。

26–32 分鐘

口頭匯報

每組派代表，用「因為……所以……」說出最少兩組因果關係，例如「因為細菌把氨轉化，所以魚不會中毒」。

32–35 分鐘

總結・延伸

齊讀口訣「魚排氨、菌轉化、菜吸收、水回流、陽光供能」，佈置回家觀察記錄任務。

05 / Student Tasks

學生任務：觀察 ＋ 拼圖 ＋ 表達

三個任務層層遞進，從「看見」到「說得清楚」。

任務 A

🔍 實地觀察記錄

  • 水：清澈還是混濁？有沒有異味？
  • 魚：游動活躍嗎？集中在哪裡？
  • 菜：根是白色還是褐色？根毛多嗎？
  • 其他：水面有氣泡嗎？過濾區有甚麼？

觀察小提醒

  • 先看整體，再看細節
  • 用比較：這一池和魚缸有甚麼不同？
  • 記錄要用具體描述，不寫「很靚」
任務 B

🧩 小組拼循環圖

  • 把五張要素卡排成一個閉合的循環
  • 用箭頭標出養分流向與水流方向
  • 指出「細菌」應該放在哪兩個角色之間
  • 向組員解釋為甚麼要這樣排

檢查清單

  • 循環有沒有「缺口」？
  • 陽光的位置放對了嗎？
  • 水是不是連接了所有角色？
任務 C

🗣️ 口頭說因果

  • 用「因為……所以……」說出最少兩組關係
  • 例如：因為細菌把氨轉化，所以水質變好
  • 例如：因為菜吸收硝酸鹽，所以水可以回流魚池
  • 組員要輪流發言，其他人專心聆聽

表達小貼士

  • 先說「因為」，停一秒，再說「所以」
  • 配合手勢指向共生池的位置

06 / Assessment & Extension

評估與延伸

怎樣知道學生真的學會了？看他們能否把「看過的」變成「說得出的」。

評估面向 觀察指標 表現示例
知識 能指出五要素及其角色 說出「細菌負責把氨轉成硝酸鹽」
技能 能排出正確的循環圖 小組拼圖無缺口，箭頭方向正確
表達 能用因果句式說明關係 「因為菜吸收硝酸鹽，所以水變乾淨」
態度 能愛護生物、珍惜水資源 不拍打水面、主動提醒同學守規則

🏠 課後延伸活動

  • 1. 用膠樽設計一個迷你魚菜共生瓶，一星期後拍照記錄。
  • 2. 連續七天記錄家中魚缸或盆栽的水色變化，嘗試解釋原因。
  • 3. 訪問家人：以前種菜要施肥，現在魚菜共生為甚麼不用？
  • 4. 畫一張「我家的共生循環圖」，下節課與同學分享。

💡 常見迷思拆解

  • ✕ 「魚菜共生就是魚和菜一起養。」→ 其實關鍵是「細菌」與「循環」。
  • ✕ 「水會越來越臭。」→ 只要細菌與植物正常工作，水會越來越清。
  • ✕ 「植物靠魚的糞便直接吸收養分。」→ 要經過細菌兩步轉化才行。
  • ✕ 「不用陽光也可以。」→ 沒有陽光，植物無法光合作用，系統就斷電。

① 五要素，缺一不可

魚、菜、細菌、水、陽光各有角色，任何一個消失，循環就會斷開。

② 細菌是關鍵橋樑

氨 → 亞硝酸鹽 → 硝酸鹽，兩步硝化作用把毒物變成肥料。

③ 水是運送媒介

水把養分、廢物、氧氣送到每一個角色手上，讓循環真正「連起來」。

④ 陽光是能量源頭

植物靠光合作用製造養分並放出氧氣，整個系統靠它供能。
