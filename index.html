02 / Five Elements

五要素角色：缺一不可的共生團隊

魚菜共生不是「魚 + 菜」這麼簡單，而是五個角色各司其職、互相支撐的系統。在聖卡洛生命園-樂天綠色共生園，這裡的「菜」是水中植物（如荷花、浮萍等），不是葉菜。

👉 點擊卡片，看看每個角色在系統裡做甚麼。

🐟

魚

排廢者・養分起點

魚吃飼料後把蛋白質分解，經鰓和排泄物把含氮廢物「氨」排到水裡。牠是整個循環的養分起點，但氨太多會令牠自己生病。

點擊看角色

🌿

菜（植物）

吸收者・淨水高手

在魚菜共生裡，植物吸收硝酸鹽來製造蛋白質和葉綠素，一邊吸收養分，一邊把水變乾淨，是系統裡的天然濾水器。在這個園，植物是水中植物（如荷花、浮萍等），長在水中，不是葉菜。

點擊看角色

🦠

細菌

轉化者・隱形功臣

硝化細菌住在生物球、砂石和過濾棉的表面。牠把有毒的氨一步步轉成亞硝酸鹽，再轉成植物能用的硝酸鹽，是整個系統最關鍵的橋樑。

點擊看角色

💧

水

媒介・運輸大隊

水把養分送到水中植物（如荷花、浮萍等），把廢物帶到細菌區，再把潔淨的水送回魚生活的地方。它像一條馬路，讓所有角色可以「互相見面」。

點擊看角色

☀️

陽光

能量來源・幕後老闆

植物靠光合作用把光能變成養分，同時放出氧氣供魚呼吸。沒有陽光，植物長不大，整個循環就沒有能量來源。

04 / Student Tasks

學生任務：觀察 ＋ 拼圖 ＋ 表達

三個任務層層遞進，從「看見」到「說得清楚」。

任務 A

🔍 實地觀察記錄

  • 水：清澈還是混濁？有沒有異味？
  • 魚：游動活躍嗎？集中在哪裡？
  • 你認識水中的植物嗎？它在水中有什麼作用？
  • 其他：水面有氣泡嗎？過濾區有甚麼？

觀察小提醒

  • 先看整體，再看細節
  • 用比較：這一池和魚缸有甚麼不同？
  • 記錄要用具體描述，不寫「很靚」
任務 B

🧩 小組拼循環圖

  • 把五張要素卡排成一個閉合的循環
  • 用箭頭標出養分流向與水流方向
  • 指出「細菌」應該放在哪兩個角色之間
  • 向組員解釋為甚麼要這樣排

檢查清單

  • 循環有沒有「缺口」？
  • 陽光的位置放對了嗎？
  • 水是不是連接了所有角色？

任務 C

🗣️ 口頭說因果

  • 用「因為……所以……」說出最少兩組關係
  • 例如：因為細菌把氨轉化，所以水質變好
  • 例如：因為水中植物（如荷花、浮萍等）吸收硝酸鹽，所以水可以回流
  • 組員要輪流發言，其他人專心聆聽

表達小貼士

  • 先說「因為」，停一秒，再說「所以」
  • 配合手勢指向園裡的水中植物

口訣裡的「菜」，在本園是水中植物（如荷花、浮萍等）。

① 五要素，缺一不可

魚、菜、細菌、水、陽光各有角色，任何一個消失，循環就會斷開。在聖卡洛生命園-樂天綠色共生園，菜是水中植物（如荷花、浮萍等）。

② 細菌是關鍵橋樑

氨 → 亞硝酸鹽 → 硝酸鹽，兩步硝化作用把毒物變成肥料。

③ 水是運送媒介

水把養分、廢物、氧氣送到每一個角色手上，讓循環真正「連起來」。

④ 陽光是能量源頭

植物靠光合作用製造養分並放出氧氣，整個系統靠它供能。
