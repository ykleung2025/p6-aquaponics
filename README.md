# 小六魚菜共生理念與原理

這是小學六年級「魚菜共生的理念與原理／參觀校園共生池」教學網頁。

用瀏覽器開啟根目錄的 `index.html` 即可閱讀。內容包括學習目標、五要素、氮循環、參觀流程、任務與評估。

## 拼循環圖遊戲

`cycle.html` 是給課堂和平板使用的拖放遊戲。學生把魚、益菌、植物和水（養分媒介）拖到循環圖的正確位置：魚排出氨，益菌把氨轉成養分，植物吸收養分並淨化水質，清水再流回魚缸。放錯會看到一句科學小提示；四個都放對就顯示「過關」。可以按「再玩一次」重新洗牌。遊戲沒有計時，也沒有分數，介面只用繁體中文。

從教學頁的「拼循環圖遊戲」可進入，或直接開啟 `cycle.html`。
