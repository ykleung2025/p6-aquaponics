# 小六魚菜共生理念與原理

這是小學六年級「魚菜共生的理念與原理／參觀校園共生池」教學網頁。

用瀏覽器開啟根目錄的 `index.html` 即可閱讀。內容包括學習目標、五要素、氮循環、參觀流程、任務與評估。

## 拼循環圖遊戲

課堂上保留兩款拼循環圖，方便比較。兩款都沒有計時、沒有分數，介面只用繁體中文。

- `cycle.html`：現有課堂版。學生把魚、益菌、植物和水（養分媒介）拖到循環圖的正確位置：魚排出氨，益菌把氨轉成養分，植物吸收養分並淨化水質，清水再流回魚缸。放錯會看到一句科學小提示；四個都放對就顯示「過關」。可以按「再玩一次」重新洗牌。
- `cycle-deepseek.html`：DeepSeek 課堂版。學生把魚、有益細菌、植物和清水拖到循環圖的提示位置。放對會鎖定，放錯會搖一搖並提示再想想；四格都對就顯示完成說明。可以按「再玩一次」。

從教學頁的「拼循環圖遊戲」進入現有版本，或從「拼循環圖（DeepSeek 版）」進入 DeepSeek 版本。
